# Grid drainage contract v1

输入 cell_size_m 为1..10000整数米，elevations 为非空矩形数组，最多100000格。
有效高程为-10000..10000整数米，null为无数据；全null矩形合法，输出0有效面积。
行从北到南、列从西到东；这是合成平面规则网格，没有EPSG或真实地球曲率假定。

每格仅流向8邻域内严格更低且下坡最陡的有效格。正坡度使用落差平方/步长平方精确比较，
对角步长平方为2、正交为1，不用浮点近似判并列；共同cell_size可消去。
坡度相同时按下游行列字典序选择。无更低邻居则为终点，包括平地与局部洼地。
网格外和null不构成排水出口；对角可跨过两个正交null邻居，按8邻域定义而非河道连通。
没有填洼、平地解流、海岸出口或降雨入渗模型，因此不能把结果当洪水风险预测。

严格下降使图天然无环。按高程从高到低累加每格自身贡献1；upstream_cells包括自身。
contributing_area=upstream_cells*cell_size_m²；不把所有格贡献面积相加当流域面积。
终点集水面积之和=有效格总面积，每格恰归一个终点。输出每格下游、贡献格数和终点，
另给终点集水区面积。示例12格/48m²，终点[2,2]归9格/36m²，[2,4]归3格/12m²。

当前只有JSON格网，尚无真实GeoTIFF读写、外存分块、河网矢量化或大规模并行。
此小型基线便于独立核验流向和面积，不是完整GIS套件。
