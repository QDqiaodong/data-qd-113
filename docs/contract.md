# Grid drainage contract v1

输入 cell_size_m 为1..10000整数米，elevations 为非空矩形数组，最多100000格。
有效高程为-10000..10000整数米，null为无数据；全null矩形合法，输出0有效面积。
行从北到南、列从西到东；这是合成平面规则网格，没有EPSG或真实地球曲率假定。

每格仅流向8邻域内严格更低且下坡最陡的有效格。正坡度使用落差平方/步长平方精确比较，
对角步长平方为2、正交为1，不用浮点近似判并列；共同cell_size可消去。
坡度相同时按下游行列字典序选择。无更低邻居则为终点，包括平地与局部洼地。
网格外和null不构成排水出口；对角可跨过两个正交null邻居，按8邻域定义而非河道连通。
没有填洼、平地解流、海岸出口或降雨入渗模型，因此不能把结果当洪水风险预测。

严格下降使图天然无环。按高程从高到低累加每格自身贡献1；upstream_cells包括自身。
contributing_area=upstream_cells*cell_size_m²；不把所有格贡献面积相加当流域面积。
终点集水面积之和=有效格总面积，每格恰归一个终点。输出每格下游、贡献格数和终点，
另给终点集水区面积。示例12格/48m²，终点[2,2]归9格/36m²，[2,4]归3格/12m²。

当前只有JSON格网，尚无真实GeoTIFF读写、外存分块、河网矢量化或大规模并行。
此小型基线便于独立核验流向和面积，不是完整GIS套件。

## 可选阈值河网（`--stream-threshold N`）

未给出参数时报告与上文完全一致，不新增字段。给出正整数N时，在原报告追加
`stream_network`，其余字段内容不变。阈值不是正整数的输入按校验失败处理，退出2
并保留原输出。

河网成员仅限`upstream_cells >= N`的有效格；全null或阈值过大时`cell_count`、
`edge_count`为0，`nodes`与`chains`为空数组。边直接使用已算出的D8下游，不重算流向、
坡度或贡献格数。由于下游格贡献格数不小于本格，河网对下游封闭，故河网内每条边
都落在唯一的节点间极大有向链上。

节点是河网内入度不为1的格，或无下游的格；节点按`(row,col)`升序编号0..k-1。
每条链从某节点出发，沿D8下游走到下一个节点为止，两端坐标都包含在链中。
每个节点至多产生一条链，于是每条河网边恰出现一次、无重复。孤立河网格（入度
为0且无下游）只作为节点出现，不产生链。链按起点节点编号（即起点行列序）编号
0..m-1，因此节点与链的编号只取决于坐标，稳定可复现。

Strahler级别按河网内支流计算：无河网支流为1，仅当至少两支支流并列达到最高
级别时加1；链的级别取起点格级别。级别在严格下降（高程降低）的拓扑序上累加，
只用整数比较。

每条链给出`orthogonal_steps`与`diagonal_steps`，长度以精确表达式
`cell_size_m*(正交步数+对角步数*sqrt(2))`表示，不写入浮点值也不据此判断拓扑。
链路径按严格下降逐格前进，用迭代遍历，长达10万格也不会递归溢出。

复杂度：设有效格数V、河网格数K、河网边数E。成员筛选与入度统计为O(V+K)，
Strahler级别按高程排序后为O(K log K)，节点排序同为O(K log K)；链压缩沿边遍历，
所有链路径长度之和恰为E，故整体O(V+K log K+E)，内存O(V+E)。未启用该参数时不
增加任何开销。
